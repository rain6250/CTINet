# Data

Raw EEG and fNIRS data are not redistributed in this repository.

Please download the original public datasets from the repositories listed below.

## Motor Imagery (MI) and Mental Arithmetic (MA)

Shin et al., "Open Access Dataset for EEG+NIRS Single-Trial Classification,"
IEEE Transactions on Neural Systems and Rehabilitation Engineering, 2017.

Dataset:
https://doi.org/10.82901/nemar.nm000267

## Word Generation (WG)

Shin et al., "Simultaneous acquisition of EEG and NIRS during cognitive tasks
for an open access dataset," Scientific Data, 2018.

Dataset:
https://doi.org/10.14279/depositonce-5830.2

The preprocessing procedures follow those described in the paper.
The training code assumes that preprocessing and spatial interpolation
have been completed before model training.
